# SilverMuzzle — Senior Dog Care

Static site for Vercel. No build step, no backend, no database.

## What is in here

- `index.html` — home, with the 3-question "Find the right product" quiz
- `categories/` — 6 category pages, each with a dog-size filter (small / medium / large / giant)
- `roundups/` — 3 roundups: orthopedic beds, dog ramps, harnesses for weak back legs
- `comparisons/` — 2 comparisons: ramp vs stairs, memory foam vs egg-crate
- `articles/` — 5 guides
- `about.html` — author bio placeholder + "How We Research Products" + hidden vet-review box
- `affiliate-disclosure.html` — Amazon Associates disclosure
- `content-plan.md` — roadmap with 40 more long-tail ideas
- `styles.css`, `script.js` — design system + quiz/filter logic
- `sitemap.xml`, `robots.txt`, `vercel.json`

## Before you publish

1. **Replace the affiliate tag.** Search the whole folder for `YOUR-AFFILIATE-TAG-20` and
   replace it with your real Amazon Associates tag, e.g. `silvermuzzle-20`.
   Amazon links are search links (`amazon.com/s?k=...&tag=...`) — swap in exact product
   links (with your tag) when you pick specific products.
2. **Replace the placeholders in `about.html`:** `[YOUR NAME]`, dog ownership experience,
   `[YOUR EMAIL]`. Do not publish with placeholders.
3. **Domain.** In Vercel: Project → Settings → Domains → add `[YOURDOMAIN.com]`.
   Point the domain's DNS to Vercel as Vercel instructs. The site uses relative links,
   so it works on any domain with no code change.
4. **AdSense later:** add your AdSense code to the `<head>` in `build.py` (the `header()`
   function) and rebuild, or paste it into each page. Do not add it until the site has
   real content live and you have applied.
5. **Vet reviewer:** the "Reviewed by a veterinarian" box in `about.html` is hidden
   (`hidden` attribute). Only unhide it with a real vet's name, qualifications and date.

## Deploy to Vercel

- Push this folder to GitHub, then in Vercel: Add New → Project → Import the repo.
  Framework Preset: **Other**. Build Command: leave empty. Output Directory: `.`
- Or drag the folder into Vercel, or run `vercel` from this folder.

## Rebuild after editing content

Pages are generated by `build.py` (Python 3, no dependencies):

```bash
python3 build.py
```

Edit the content lists in `build.py` (CATS, ROUNDUPS, COMPARISONS, ARTICLES), then
re-run it. Do not hand-edit the generated `.html` files — your edits will be lost
on the next rebuild.

## Trust and safety rules (do not break these)

- Every article and review carries: "This content is for general information only and is not veterinary advice. Always consult your vet about your dog's health."
- Never claim a product treats, cures or prevents any condition. Use "designed to support comfort."
- No nutrition or medical claims in Feeding content.
- Do not claim hands-on testing unless true.

## Alternative names (check domain availability before choosing)

SilverMuzzle is the working name. Three alternatives to check:

1. **GreyMuzzleCare.com** — clear, warm, says senior + care
2. **OldPawsComfort.com** — friendly, memorable, comfort-led
3. **SeniorPawsGuide.com** — guide-led, good for search

Check availability on Namecheap, Porkbun or Cloudflare Registrar, and check the
`.co.uk` version too if you want a UK audience. Do not buy a domain that is a
trademark of an existing pet brand.
